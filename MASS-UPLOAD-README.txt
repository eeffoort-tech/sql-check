ДОПОЛНИТЕЛЬНАЯ ФУНКЦИЯ: МАССОВАЯ ЗАГРУЗКА ТОВАРОВ
============================================================

НОВЫЕ ФАЙЛЫ:
------------
1. mass-upload.html      - Страница массовой загрузки
2. mass-upload.css       - Стили страницы загрузки
3. mass-upload.js        - Логика массовой загрузки
4. column-config.html    - Управление профилями магазинов
5. column-config.css     - Стили настроек
6. column-config.js      - Логика профилей
7. xlsx.full.min.js      - Библиотека для Excel
8. init-mass-upload.js   - Скрипт инициализации
9. sql-init-massupload.sql - SQL для создания таблицы

============================================================
СТРУКТУРА БД:
============================================================

mass_upload (единая таблица):
  id           - уникальный ID
  type         - 'config' (профиль) или 'upload' (журнал)
  store_name   - название магазина (для type='config')
  kod_col      - колонка с кодом
  name_col     - колонка с наименованием
  qty_col      - колонка с количеством
  filename     - имя файла (для type='upload')
  upload_date  - дата загрузки
  file_hash    - хеш содержимого
  record_count - кол-во записей
  user_id      - ID пользователя
  created_at   - дата создания

wneshkod:
  kod  - внутренний код (из guide)
  wkod - внешний код (из CSV/Excel)

============================================================
УСТАНОВКА:
============================================================

1. Выполните SQL из sql-init-massupload.sql
2. Создайте профили магазинов в "Настройки колонок"
3. Загружайте файлы в "Массовая загрузка"

============================================================
ИСПОЛЬЗОВАНИЕ:
============================================================

ШАГ 1: Создать профиль магазина
---------------------------------
1. Панель → "Настройки колонок"
2. "+ Добавить профиль"
3. Укажите:
   - Название магазина (например: "Магнит")
   - Колонка с кодом (например: "kod_art")
   - Колонка с наименованием (опционально)
   - Колонка с количеством (опционально)
4. "💾 Сохранить профиль"

ШАГ 2: Массовая загрузка
-------------------------
1. Панель → "Массовая загрузка"
2. Выберите магазин из списка
3. Загрузите файл (CSV, Excel)
4. Система автоматически подставит колонки
5. Проверьте и подтвердите

============================================================
ФОРМАТЫ ФАЙЛОВ:
============================================================
✅ CSV (.csv) — разделитель ;
✅ Excel (.xlsx, .xls) — первый лист
✅ TXT/TSV (.txt, .tsv) — разделитель ;

============================================================
ЛОГИКА ПОИСКА:
============================================================
1. Код из CSV → ищем в wnes kod.wkod
2. Если нашли → берём wnes kod.kod
3. Ищем этот kod в guide.kod
4. Если нашли → товар найден ✅
